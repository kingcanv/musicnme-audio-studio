# MusicNMe Audio Studio

iPhone 风格的音频播放 / 混音工作室单页应用。

## 预览

打开 `index.html` 即可在浏览器中运行（建议使用 Chrome / Safari 最新版）。

## 功能

- 多轨音频混音（独立音量 / 静音 / 独奏）
- 播放 / 暂停 / 快退 / 快进（1 秒）
- 实时均衡器 (EQ) 与可视化
- 录制与导出混音
- iPhone 风格的毛玻璃 / 圆角 / 拟物 UI

## 部署

本项目为纯静态单文件，直接打开 `index.html` 即可。也可托管到 GitHub Pages、Vercel、Netlify 等。
